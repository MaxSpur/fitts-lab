What is measured, what is shared, and what can this tell us?

The acquisition time runs from activation of a target to a primary-button press. It includes reaction and any correction; it is not a movement-onset measurement. Starting clicks are unscored. A miss stays in the data; the target remains active until a successful click. Retry attempts are identifiable separately. Pausing invalidates only the unfinished movement, with an interruption entry retained in the set log.

Distances and coordinates are CSS pixels in the experiment area. Interface boundaries are simulated through Pointer Lock; OS cursor acceleration remains in use. Different devices and display configurations can have different intercepts and slopes. These short sets are a classroom illustration, not a device benchmark or a controlled experiment.

Completed attempts, sampled trajectories, settings, and set history are saved in this browser’s IndexedDB. Storage can be cleared or evicted by the browser, so export important sessions. Joining a classroom shares only new attempts made afterward, with a random participant label. It shares sampled paths, geometry, timings, and device-pixel ratio—not your name, email, keystrokes, or screen contents. Hosting services can retain network access logs. Stop sharing before returning to individual exploration.

Throughput and statistically effective width are deliberately omitted from this short demo: sparse sets and clamped endpoints make them easy to misinterpret. Source references and further mathematical notes are in Methods.

Fitts’ law

Distance, width, and time

Fitts’ law relates pointing time to target distance D and width W. Farther or smaller targets generally take longer to select. The plots use the Shannon formulation:

ID = log₂(1 + D/W)   ·   T = a + b · ID

ID is difficulty in bits; a is the fitted intercept in milliseconds, and b is milliseconds per bit. For example, D/W = 7 gives 3 bits. With a = 100 ms and b = 100 ms/bit, the predicted time is 400 ms.

Why a logarithm?

A useful analogy is successive halving. Reducing an interval L to width W in k steps gives L/2ᵏ = W, hence k = log₂(L/W). Each halving adds one bit. This motivates the logarithm; it does not describe literal steps of the hand.

The relationship with time is empirical. The Shannon form stays nonnegative, and doubling both distance and width leaves difficulty unchanged. The formulations below use different indices and require separately fitted coefficients. Fitts (1954); MacKenzie (2013).

Width along the approach

D runs from Start to the target center. The highlighted segment, W∥, is the target’s width along that line. Moving vertically or changing height can change this width too.

Shannon is used in the plots. Zero difficulty does not imply zero time: the fitted model still gives T = a.

Two-dimensional targets and boundaries

For a rectangle of width w and height h, this app uses the line through the center in the approach direction:

W∥ = min(wD/|Δx|, hD/|Δy|)

Here D = √(Δx² + Δy²); a zero component imposes no constraint. This center chord is a geometric approximation, not a universal width definition. MacKenzie & Buxton (1992).

Along that line, near and far edges n and f give D = (n + f)/2 and W∥ = f − n. Fix n and let f → ∞:

D/W∥ = (1 + n/f) / [2(1 − n/f)] → ½

A screen edge instead stops overshoot in one direction. Travel and precision along the edge remain. The experiment compares matched free/edge sets separately, without assigning hard edges a scalar difficulty.

Reading the results

Time runs from target activation to button press, including reaction and correction. Fits use successful first attempts; misses stay visible. Read time together with error rate. R² describes fit, not causation.

Coordinates are CSS pixels, not physical measurements. Device, browser, practice, and strategy affect performance. Free sets always precede edge sets, so practice may influence the comparison. Repeat runs belong to the same student; students contributing more trials have more weight in pooled fits.

Statistical effective width comes from repeated endpoint variation. It differs from the geometric width used here. These short, varied sets do not provide a calibrated throughput score. Soukoreff & MacKenzie (2004). See measurement definitions for details.
