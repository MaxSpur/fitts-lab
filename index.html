What is measured, what is shared, and what can this tell us?

The acquisition time runs from activation of a target to a primary-button press. It includes reaction and any correction; it is not a movement-onset measurement. Starting clicks are unscored. A miss stays in the data; the target remains active until a successful click. Retry attempts are identifiable separately. Pausing invalidates only the unfinished movement, with an interruption entry retained in the set log.

Distances and coordinates are CSS pixels in the experiment area. Interface boundaries are simulated through Pointer Lock; OS cursor acceleration remains in use. Different devices and display configurations can have different intercepts and slopes. These short sets are a classroom illustration, not a device benchmark or a controlled experiment.

Completed attempts, sampled trajectories, settings, and set history are saved in this browser’s IndexedDB. Storage can be cleared or evicted by the browser, so export important sessions. Joining a classroom shares only new attempts made afterward, with a random participant label. It shares sampled paths, geometry, timings, and device-pixel ratio—not your name, email, keystrokes, or screen contents. Hosting services can retain network access logs. Stop sharing before returning to individual exploration.

Throughput and statistically effective width are deliberately omitted from this short demo: sparse sets and clamped endpoints make them easy to misinterpret. Source references and further mathematical notes are in Methods.

Method

From target geometry to pointing time

A model of the trade-off between speed and precision. Start with the geometry, explore the formula, then read your results.

1. Distance sets the journey; width sets the tolerance

Let D be the distance from the starting point to the target’s centre, and W its width along the direction of approach. Increasing distance asks for a longer movement. Reducing width asks for a more precise endpoint. Fitts studied this relationship by varying movement amplitude and target width in repeated aiming tasks. Fitts, 1954.

The ratio D/W combines these two demands. Doubling both leaves the ratio unchanged: a target twice as far away and twice as wide has the same modelled difficulty. This is a geometric prediction; physical scale, input device, and posture can still affect performance.

2. Why a logarithm?

As an intuition, imagine repeatedly halving a region of uncertainty until it is as small as the target. After k halvings, L/2ᵏ = W, so k = log₂(L/W). Each halving adds one binary decision, or bit. This is a way to understand the logarithm, not a claim that your hand literally makes those steps.

For the formulation used in these plots, take the dimensionless quantity 1 + D/W:

ID = log₂(1 + D/W)

ID is the index of difficulty, in bits. The +1 keeps it non-negative and gives zero when D = 0. This is the Shannon formulation, inspired by information theory. Its usefulness is established by fitting observations, not by deriving human motion from a communication channel. MacKenzie, 2013.

3. From bits to milliseconds

The second step is empirical: fit a line between difficulty and observed time.

T = a + b · ID

a is the fitted intercept, in milliseconds. b is the fitted increase in milliseconds per bit. Neither is a universal human constant. For example, with illustrative values a = 100 ms and b = 100 ms/bit, a target with D/W = 7 has ID = 3 bits and a predicted time of 400 ms.

Increasing 1 + D/W by a factor of two adds exactly one bit, hence b milliseconds to that fitted prediction. Doubling distance alone adds almost one bit only when distance is large relative to width.

Our T starts when the target becomes active and ends at the button press, so it includes seeing the cue and correcting the movement. The plots fit successful first attempts; hollow marks keep misses visible. Read time together with the error rate. R² describes how closely the displayed data follows the fitted line; it does not establish a cause or guarantee a prediction for another person.

4. What happens at an edge?

A target occupies the interval from near edge n to far edge f, measured from the starting point. Its geometry is:

D = (n + f)/2   ·   W = f − n

Hold n fixed and extend f. Both distance to the centre and width grow. Dividing by f shows the limit directly:

D/W = (1 + n/f) / [2(1 − n/f)] → ½

Substituting this ratio gives 0 bits for Fitts and Welford, and log₂(3/2) for Shannon. The difference follows from the equations. It does not imply zero movement time. With a fitted intercept, zero difficulty still gives T = a; extending a target indefinitely also goes beyond the finite targets used to fit the model.

A screen edge is a different physical constraint: it catches overshoot in one direction. You still travel to it, and a menu item still requires precision along the edge. Our free/edge pairs keep their geometry and captured input matched. They are compared separately, without assigning a scalar difficulty to hard-edge trials.

Two-dimensional targets: which width?

For circles, any centre-directed approach has the same target diameter. For a rectangle, the available tolerance changes with direction. This app uses the length of the line through the centre along the approach vector:

W∥ = min(wD/|Δx|, hD/|Δy|),   D = √(Δx² + Δy²)

A zero component places no constraint in that term. A horizontal approach gives width w; a vertical approach gives height h. This centre chord is our explicit geometric approximation, not a universal law for rectangles. Width definitions for two-dimensional tasks have been compared empirically. MacKenzie & Buxton, 1992.

Reading this classroom experiment

Horizontal and Circles balance planned distance and size. Interface buttons vary both dimensions and position; menu/window sets compare matched free and bounded sequences, always free first. Practice can therefore influence the comparison. All sets have one unscored start and continue directly between successful selections.

Coordinates use CSS pixels, not physical millimetres. Device and browser behavior, visual search, practice, and individual strategies add variation. Repeated trials and repeat runs belong to the same person; they are not independent new participants. Classroom trendlines pool observations within compatible settings, so students contributing more trials have more weight.

Effective width is a separate statistical quantity inferred from the spread of repeated endpoints; it is not the painted width used here. The short, varied sets and clamped boundary endpoints are not a basis for a calibrated throughput score. Soukoreff & MacKenzie, 2004.
